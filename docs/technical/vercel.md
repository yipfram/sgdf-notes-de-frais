# Deploiement Vercel

## Variables d'environnement

Variables optionnelles et exemples fournisseurs : [Variables d'environnement](/technical/environment-variables).

## Etapes

1. Importer le repo GitHub dans Vercel
2. Ajouter les variables d'environnement
3. Deployer
4. Ajouter le domaine Vercel dans Clerk et activer **Organizations**
5. Vérifier que les responsables peuvent créer un groupe et inviter un membre
6. Configurer puis confirmer l’adresse de trésorerie du groupe
7. Tester connexion + envoi d'e-mail
